# Lab 1 — Python basics

## 1. Variable practice

**Question:** Create variables of different types and show each value with its type.

**Approach:** I stored name, age, height, and student status in variables and printed them with `type()`.

File: `variable_practice.py`

## 2. Greeting program

**Question:** Take the user’s name, age, and city and display them.

**Approach:** I used `input()` for name, age, and city, then printed the values in one f-string.

File: `greeting_program.py`

## 3. Arithmetic operations

**Question:** Take two numbers and show sum, difference, product, quotient, and remainder.

**Approach:** After reading two integers, I printed all five results using `+`, `-`, `*`, `/`, and `%`.

File: `arithmetic.py`

## 4. Celsius to Fahrenheit

**Question:** Convert a temperature from Celsius to Fahrenheit.

**Approach:** I read Celsius as a float and used the formula `(celsius * 9 / 5) + 32`.

File: `celsius to fahrenheit.py`

## 5. String manipulation

**Question:** Take a full name and show uppercase, lowercase, reverse, and length.

**Approach:** I used `.upper()`, `.lower()`, slicing `[::-1]`, and `len()` on the input string.

File: `string_manipulation.py`

## 6. Escape sequences

**Question:** Use `\t` and `\n` to format output like a small menu or list.

**Approach:** I printed item names and prices on separate lines with a tab between name and price.

File: `escape_sequence.py`
