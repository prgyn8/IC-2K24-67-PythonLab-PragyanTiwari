# Lab 4 — Patterns and matrices

## 1. Star pattern

**Question:** Take `n` and print a star pattern with increasing stars per row.

**Approach:** Nested loops: outer loop for each row, inner loop prints `i` stars on that row.

File: `star.py`

## 2. Matrix operations

**Question:** Read a 3×3 matrix and show sum of all elements, main diagonal sum, largest and smallest element, and transpose.

**Approach:** I used small functions: `make_matrix` to fill a list of lists from input, loops to add elements and diagonal, compare values for min/max, and swap indices when printing the transpose.

File: `matrix.py`
